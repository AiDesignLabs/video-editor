# 视频编辑功能路线图

本文记录编辑器已经具备的主要能力，以及后续版本需要补齐的功能。优先级根据用户价值、实现成本和对现有架构的影响综合确定。

状态说明：

- `已完成`：已有可用的协议、编辑命令、界面和渲染链路。
- `部分完成`：已有底层能力，但缺少完整的用户操作链路。
- `待实现`：尚未形成可用能力。

## 当前能力

以下能力已经具备，不列入后续开发范围：

- 画布元素的移动、缩放和旋转。
- 图片、视频和音频素材导入，以及本地资源存储。
- 视频缩略图和音频波形。
- 时间轴吸附、分割、复制、粘贴、重复和波纹删除。
- 轨道隐藏和静音。
- 转场库，以及外部转场和特效注册机制。
- 矩形蒙版、椭圆蒙版和色键。
- 关键帧、音量淡入淡出和倒放。
- 工程保存、加载和删除。
- MP4、WebM 导出及基础导出参数设置。

## P0：补齐核心编辑流程

### 修改视频画布尺寸

**状态：已完成。** 提供 `editor-core.commands.setCanvasSize()`、`CanvasSizePanel` 预设界面，
预览按工程宽高比信箱化显示。

实现要点：

- `videoBasicInfo` 的 `width`/`height`/`fps` 原本是构造时的快照拷贝，和 `updateProtocol`
  形成两个真相源 —— 撤销恢复一个、导出写回另一个。已改成可写 computed，读写都直通协议状态。
- 预览此前按**容器**尺寸建舞台，工程宽高只在导出时生效；现在按工程宽高比在容器内信箱化。
- 无效宽高返回 `{ success: false, error }`，不改动画布、不进撤销栈。

原始需求（均已满足）：

- 提供常用画布比例和尺寸预设，包括横屏、竖屏、方形，以及自定义宽高。
- 支持交换宽高，并显示当前宽高和宽高比。
- 通过 `editor-core.commands` 修改工程尺寸，禁止业务层直接修改协议状态。
- 将一次尺寸修改记录为一个撤销步骤，并支持重做。
- 修改后立即更新预览区域的宽高比，不拉伸预览画面。
- 保留现有素材的归一化位置、缩放和旋转；素材如何填充新画布继续由 `fillMode` 决定。
- 工程保存、重新打开和导出时使用修改后的尺寸。
- 对无效宽高给出明确错误，不静默回退到默认尺寸。

验收标准：

- 用户可以通过预设或自定义输入修改画布尺寸。
- 修改画布尺寸后，预览、工程数据和默认导出尺寸保持一致。
- 撤销和重做可以完整恢复画布尺寸及预览状态。
- 横屏与竖屏互换后，已有素材不会被意外拉伸或移出协议数据。
- 协议校验、编辑命令、工程持久化和导出链路均有测试覆盖。

### 轨道管理

**状态：部分完成。** 当前支持轨道隐藏和静音，但缺少完整的轨道结构编辑能力。

需要实现：

- 新增、删除和重排轨道。
- 锁定轨道，阻止轨道内片段被移动、裁剪或删除。
- 独奏音频轨道，并明确独奏与静音同时存在时的规则。
- 所有轨道操作接入撤销和重做。

### 多片段与关联编辑

**状态：待实现。**

需要实现：

- 框选、追加选择和取消选择多个片段。
- 批量移动、删除、复制和调整公共属性。
- 组合与取消组合片段。
- 关联与取消关联视频、音频片段，移动和裁剪时保持同步。

### 字幕工作流

**状态：待实现。**

需要实现：

- 导入和导出 SRT、ASS、VTT 字幕文件。
- 批量编辑字幕文本、时间和样式。
- 提供字幕样式预设，并允许统一更新同组字幕。
- 对时间重叠、空文本和非法时间范围提供校验提示。

## P1：增强常用编辑效率

### 素材拖入时间轴

**状态：部分完成。** 素材可以导入并添加到工程，但缺少从素材面板直接拖入目标轨道和目标时间的完整交互。

需要实现拖入预览、目标轨道提示、时间位置计算、不合法目标提示，以及与时间轴吸附规则的统一处理。

### 变速曲线

**状态：待实现。** 当前仅支持片段级固定 `playRate`。详细设计见 [RFC 0003：Speed Curves](./rfcs/0003-speed-curves.md)。

首个版本需要实现速度关键帧、时间与源时间映射、分割和裁剪后的曲线重建、预览与导出一致性，以及最小可用的变速编辑界面。

### 高级时间轴编辑

**状态：待实现。**

需要实现：

- 时间轴标记和入点、出点范围。
- 滑移编辑、滑动编辑和滚动编辑。
- 替换素材，同时保留片段的时间、变换和效果设置。
- 更清晰的吸附目标提示和冲突反馈。

### 音频编辑

**状态：部分完成。** 当前支持音量、淡入淡出、固定变速和倒放。

后续需要实现分离视频音频、轨道混音、自动闪避、人声录制、均衡器和降噪。保留音高的变速应与变速曲线方案一起评估。

### 高级蒙版

**状态：部分完成。** 当前支持矩形和椭圆蒙版。

后续需要实现自由路径蒙版、控制点编辑、蒙版关键帧和运动跟踪。背景移除和对象分割属于独立的智能处理能力，不与基础蒙版编辑绑定。

## P2：工程化与复杂项目支持

### 素材管理

- 素材文件夹、搜索、筛选和标签。
- 重复素材识别。
- 离线素材提示和重新关联。
- 工程打包时收集所需素材。

### 导出任务管理

- 导出预设、任务队列和历史记录。
- 取消、失败重试和明确的错误信息。
- 后台导出，以及页面关闭前的任务状态提示。

### 性能优化

- 代理素材生成和切换。
- 预览渲染缓存及失效规则。
- 大型工程的增量加载和资源回收。
- 光流慢动作等高成本处理能力。

## 建议实施顺序

1. ~~完成画布尺寸修改~~（已完成），继续轨道管理和多片段编辑，补齐基础编辑闭环。
2. 完成素材拖入时间轴和字幕工作流，提升高频操作效率。
3. 按 RFC 0003 实现变速曲线，并保证预览与导出一致。
4. 增强音频、时间轴和蒙版能力。
5. 最后补齐素材管理、导出任务管理和大型工程性能优化。
