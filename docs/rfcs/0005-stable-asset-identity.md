# RFC 0005：稳定素材标识与引用安全

- 状态：已采纳
- 创建日期：2026-09-02
- 范围：P0-B 素材标识、解析和删除保护

## 1. 决策

带媒体来源的片段新增可选 `assetId`，同时继续保存 `url`。`assetId` 是素材库中的稳定身份，
`url` 是最后一次可用的地址，也是旧工程和素材记录缺失时的兼容路径。旧协议不需要迁移即可读取。

素材库清单是 `assetId` 到当前 URL 的唯一映射。`relinkAsset()` 只更新清单，不重写工程内的片段；
预览和导出在读取媒体前通过 resolver（解析器）取得当前 URL。

## 2. 解析规则

`resolveProtocolAssetUrls()` 只修改协议副本：

1. 片段没有 `assetId` 时直接使用 `url`。
2. resolver 返回新地址时使用新地址。
3. resolver 找不到记录时使用片段保存的最后可用 `url`。
4. resolver 返回空字符串时明确失败，避免把缺失依赖隐藏成加载错误。

`createRenderer()` 接收 `resolveAssetUrl`，并提供 `refreshAssets()`，使地址变化后无需修改协议即可
刷新预览。`composeProtocol()` 在任务开始时解析一次，画面和音频使用同一份解析结果。

## 3. 删除保护

`removeAsset()` 必须显式接收需要保护的协议列表。只要片段的 `assetId` 匹配，删除就失败；对没有
`assetId` 的旧协议，片段 URL 与素材 URL 相同时也视为引用。错误会列出引用片段 ID。

调用方负责传入所有需要保护的已打开或已保存工程。缺少删除上下文是调用错误，不能绕过检查。

## 4. 缓存失效

每个新导入素材从 revision 1 开始。素材重新关联后 revision 加一，素材库清单立即使用新 URL，
并把旧地址保存在 `previousUrls`。旧地址继续参与旧协议的引用检查，对应二进制在素材真正删除前
保留。

代理素材通过 `derivation` 记录 `sourceAssetId` 和生成时的 `sourceRevision`。预览请求
`preferProxy` 时只选择与原始素材当前 revision 一致的代理；导出不请求代理，继续使用原始地址。
原始素材 revision 变化后，旧代理可追踪但被视为过期，不会继续进入预览。

缩略图、波形和媒体元数据以实际来源 URL 建立缓存键。素材重新关联或删除时，
`invalidateResourceDerivatives()` 清理旧 URL 的上述派生缓存。波形缓存键同时包含资源目录、采样数
和声道，避免不同提取参数互相复用。

## 5. 后续范围

完整代理生成任务、进度和长片调度属于 P0-C。本 RFC 只建立稳定身份、代理来源版本、当前地址
解析和派生缓存失效规则。
